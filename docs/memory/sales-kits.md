### Как доставать файлы из шары застройщика

Два способа, второй лучше.

**Способ 1 — через коннектор.** Индекс Google Drive отдаёт из «Доступных мне»
только то, что владелец аккаунта хоть раз открывал: у файла появляется
`viewedByMeTime`. Пока файл не открыли, папка видна по ID, а содержимое
возвращается пустым. Значит человеку приходится кликать по каждому файлу.

**Способ 2 — разбор HTML страницы папки. Открывать ничего не нужно.**
Страница расшаренной папки отдаётся анонимно и несёт полный список файлов
в переменной `window['_DRIVE_ivd']`:

```bash
curl -sSL -A "Mozilla/5.0 ..." "https://drive.google.com/drive/folders/<FOLDER_ID>"
```

Значение экранировано через `\xNN`, после `unicode_escape` из него достаются
пары «id файла, имя». Так нашлись все 50 фотографий виллы 15, ни одну из них
владелец не открывал.

**Скачивание — не через коннектор:** он отдаёт base64 прямо в ответ, и на
файлах по 8 МБ это выносит контекст. Работает анонимный
`https://drive.google.com/uc?export=download&id=<id>` — шара отвечает 200.

**Отбор.** Из полусотни кадров вслепую не выбрать: собирается контактный лист
(сетка миниатюр с подписями одним изображением), и отбор идёт по нему.
Дальше `optimize:media` и `import:media`.

### Чем он полезен фабрике

Это единственный источник **районного** уровня, который у нас есть. Киты застройщиков
описывают свой проект и молчат про район; каталог показывает рынок целиком.

Из него собрана половина таблицы на `compare-naithon-bangtao`: 19 из 40 проектов
приходятся на Банг Тао, Черн Талай и Лагуну, на Найтон — ни одного, кроме
Vista del Mar. Оттуда же форматы (кондоминиумы против посёлка вилл), размерность
проектов (272, 384, 637, 672 юнита против 24 вилл) и коридоры цен.

### Как его цитировать

**Ценовые снимки в каталоге в большинстве помечены как брокерские и неподтверждённые
отделами продаж** — сам каталог это фиксирует статусами `Third-party/current`
и `Needs sales request`. На страницах они подаются как ориентир порядка величины
с указанием даты каталога, никогда как прайс.

Районный вывод «19 из 40» — это про наш каталог, а не перепись рынка. Формулировка
на странице так и звучит: «в нашем каталоге», а не «на Пхукете».
