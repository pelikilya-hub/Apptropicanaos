# Реестр лендингов

Одна строка на домен. Строки **не удаляются**: закрытый домен всё равно
занимает интент в глазах поиска ещё долго — статус меняется на `архив`.

Статусы: `черновик` → `на проверке` → `живой` → `архив`

| slug | type | домен | интент | удар разбора (первые слова) | оффер | статус |
|---|---|---|---|---|---|---|
| `_example` | area | — | шаблон каркаса, не домен | «Пхукет продаётся картинками, а живёте вы в логистике…» | нет | шаблон |

## Как поддерживать

- создали ветку → строка со статусом `черновик`
- заполнили разбор → вписали первые слова удара
- завели оффер → в колонке «оффер» дата `validUntil`, чтобы видеть протухающие акции
- подключили домен → `живой` + домен
- закрыли → `архив`, строку оставили

Проверка пересечений:

```bash
node tooling/check-uniqueness.mjs
```
