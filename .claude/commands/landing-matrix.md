Просят масштаб: `$ARGUMENTS`

Генерировать пачку тонких копий нельзя — см. навык `organic-guardrails`.

## Что сделать вместо

1. Прочитай `docs/memory/landings-registry.md` — какие слоты уже заняты.
2. Собери матрицу **type × geo × audience**:

   | type | geo | audience | интент одной строкой | угол Фонаря |
   |---|---|---|---|---|

3. Для каждого слота проверь, что интент не пересекается с занятым.
   Пересекающиеся слоты выбрось, а не переименуй.
4. Предложи первую пачку **3–5 веток** с разными формулами Фонаря
   (пять формул перечислены в навыке `fonar-writing` — не брать одну подряд).
5. Скажи, какого брифа не хватает по каждой ветке.

Ветки создавай только после подтверждения пачки, по одной,
через `/new-landing`.

Не отдавай 50 слотов сразу как готовый план: отдай матрицу и первую пачку.
