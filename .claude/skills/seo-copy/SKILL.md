# Копирайт лендинга

## H1

```
[формат] в [гео] для [аудитории]: [сценарий]
```

Бренд в H1 **запрещён** — валидатор это блокирует.
Бренд допустим в `title` после пайпа.

## Мета

| Поле | Длина | Правило |
|---|---|---|
| `title` | 50–65 знаков | уникален среди всех доменов |
| `description` | 140–160 знаков | уникален, описывает интент, не рекламирует |
| `h1` | — | не дублирует `title` слово в слово |

Одинаковый title на разных доменах — прямой признак дверных страниц.

## FAQ

4–6 вопросов **именно этого домена**. Не общие «как купить недвижимость в Таиланде».
Вопрос должен быть таким, который задают конкретно про этот фокус.

`tooling/check-uniqueness.mjs` падает, если один вопрос встретился на двух доменах.

## Карточка объекта (только `type: project`)

```
тип · спальни · м² · вид · якорь · право · статус · цена или «по запросу»
```

Нет подтверждённой цены — пишем `по запросу`, а не диапазон «примерно».

## Перелинковка доменов

2–5 ссылок на соседние домены + одна на хаб, если хаб существует.

Анкор = **интент соседа**, не «подробнее здесь».
Валидатор блокирует анкоры вида «подробнее», «здесь», «тут», «читать далее»
и ссылки на собственный origin.

```json
"neighbors": [
  { "label": "Ката vs Карон: чем отличается уклад", "href": "https://..." }
]
```

## Язык

Один язык на страницу, из `config.language`. Не мешать абзацы RU/EN.

## Что обязано отличаться между доменами

H1 · title · description · Фонарь · лид hero · 70%+ текста разъяснений ·
FAQ · набор якорей · пресет квиза и тексты маршрутов · OG-картинка

## Что можно держать общим

UI-kit · сетка · тон · шапка/подвал как система · движок квиза ·
юридический каркас формулировок · события аналитики

## Проверка

```bash
node tooling/validate-landing.mjs --slug <slug>
node tooling/check-uniqueness.mjs
```
