# Приёмка ветки

Лендинг готов к домену, только когда пройдены **все** пункты.
Не отмечайте пункт, не выполнив команду.

## Машинная часть

```bash
node tooling/validate-landing.mjs --slug <slug> --prod
node tooling/check-uniqueness.mjs
npm run build:landing -- --slug <slug> --prod
```

- [ ] конфиг проходит схему
- [ ] Фонарь заполнен и не совпадает с другими ветками
- [ ] нет пунктов из `forbiddenClaims` и системных запретов
- [ ] title / H1 / FAQ уникальны
- [ ] `dist/` открывается без бэкенда

## Ручная часть

- [ ] квиз завершается маршрутом **без контакта**
- [ ] разъяснения без выдуманных норм
- [ ] видно, чем страница не портал
- [ ] 428px без горизонтального скролла
- [ ] один главный CTA, второй спокойный
- [ ] canonical, og, robots, sitemap смотрят только на свой домен
- [ ] секреты не в git

## Проверка в браузере

```bash
npx http-server dist -p 4321 -s &
```

Затем на 428px:

1. пройти квиз до конца — маршрут показался, полей контакта не появилось
2. перезагрузить — состояние восстановилось
3. вернуться назад — ответы не потерялись
4. посчитать липкие CTA на мобиле: должен быть ровно один
5. проверить горизонтальный скролл: `document.documentElement.scrollWidth - clientWidth === 0`

Для автоматизации есть `superpowers-chrome` (навык `browsing`).

## Секреты

Ключи аналитики и пиксели в открытый репозиторий не коммитятся.
В конфиге только имя провайдера, в `.env.example` только имена переменных.

```bash
git grep -nE "(api[_-]?key|secret|token|G-[A-Z0-9]{8})" -- . ':!*.example'
```
