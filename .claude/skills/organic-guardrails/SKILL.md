# Органические рамки

## Один домен — один интент

Лендинг закрывает **один человеческий вопрос**. Не «вся недвижимость Пхукета».

| `type` | Задача |
|---|---|
| `area` | Район: кому сюда, якоря, риски, какие форматы |
| `audience` | Аудитория: семья, инвестор, зимовка, remote |
| `project` | Один комплекс / продукт |
| `scenario` | Механика: off-plan, удалённая сделка, земля |
| `compare` | Два района или два формата |

На одном домене один `type`.
`project` не дублирует соседний `area` слово в слово: районный домен говорит
о месте, продуктовый — о конкретном инвентаре.

**Одна ветка = один домен = один поисковый интент.**
Не держать 50 доменов на одном URL-пространстве через `?project=`.

## Запрещено безусловно

- дверные домены с заменой топонима
- «лучшая недвижимость Пхукета» и любая превосходная степень про рынок
- гарантия доходности, «без риска»
- фейковый дефицит, таймер, обратный отсчёт, фейковые отзывы
- серые схемы владения землёй
- копирование карточки объекта с портала без своей рамки

Механическая проверка живёт в `tooling/forbidden.mjs` и падает на сборке.
Ветка может **добавить** свои запреты через `config.forbiddenClaims`, но не снять системные.

## Если факта нет

Пишем `[ДАННЫЕ]`. Не выдумываем: цифры рынка, yield, юридические схемы,
отзывы, «осталось N вилл».

На проде (`--prod`) любой оставшийся `[ДАННЫЕ]` блокирует деплой.

## Просят «сделать сразу 50 доменов»

Отказать в генерации 50 тонких копий. Вместо этого:

1. вернуть матрицу слотов **type × geo × audience**
2. создавать ветки пачками по 3–5
3. каждая пачка — с уникальными Фонарями, проверенными через `check-uniqueness.mjs`
