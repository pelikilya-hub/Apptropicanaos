# Стоит понять до просмотра

Блок честного разбора. Стоит после Фонаря-оффера, перед «кому / антикому».
Обязателен: без него ветка не проходит валидацию.

Это **не оффер**. Ни цены, ни срока, ни остатка здесь нет — они живут в `config.fonar`,
см. навык `fonar-writing`.

Задача: высветить неудобную правду связки **место × аудитория × формат**
и отличить домен от портала. Именно этот блок кормит органику.

## Прежде чем писать

```bash
node tooling/check-uniqueness.mjs
grep -h '"strike"' landings/*/config.json
```

Один и тот же удар на двух доменах запрещён — валидатор это блокирует.
Оффер повторяться может (одна акция застройщика на нескольких доменах), разбор — нет.

## Пять формул — выбрать одну на ветку

1. **Неудобная правда рынка.** Что все знают, но не пишут в объявлении.
2. **Кому да / кому нет.** Отсечение раньше, чем человек потратил месяц.
3. **Механика вместо прилагательного.** Не «премиальный», а как устроена сделка.
4. **Антикаталог.** Почему тут нет списка всего района.
5. **Что остаётся после ключей.** Кто управляет, кто чинит, кто платит.

Соседние домены не берут одну формулу подряд — иначе площадки читаются
как один шаблон с заменой топонима.

## Анатомия

| Часть | Правило |
|---|---|
| `label` | `Стоит понять до просмотра` или своё |
| `strike` | **12–22 слова**, serif, крупно. Валидатор считает слова |
| `body` | 2–4 предложения, спокойно |
| `splitYes` / `splitNo` | кому сюда, кому нет |
| кнопка | на `#quiz` |

## Тон

Острота разрешена именно здесь — и только здесь. В разъяснениях кричать нельзя,
а в оффере давить сроком без данных запрещено технически.

Пишите так, будто человек уже видел десятки объявлений на порталах.
Вы экономите ему месяц хаоса.

**Работает:** называет цену выбора, механику, неудобное следствие.
**Не работает:** превосходная степень, «уникальный», обещание доходности.

## Проверка

```bash
node tooling/validate-landing.mjs --slug <slug>
node tooling/check-uniqueness.mjs
```
