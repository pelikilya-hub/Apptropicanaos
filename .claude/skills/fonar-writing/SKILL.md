# Фонарь — офферный блок

Фонарь — приманка: цена, условия, срок, остаток. То, ради чего человек остановился.
Стоит сразу после hero.

Честный разбор — **другой блок**, `insight`, см. навык `insight-writing`.
Не путайте: Фонарь конвертит, разбор кормит органику.

## Фонарь необязателен

У районного или сценарного домена цены может не быть вовсе — тогда `config.fonar`
не заполняется и блок схлопывается. Не выдумывайте оффер, чтобы «блок не пустовал».

Для `type: project` отсутствие оффера почти всегда ошибка — валидатор предупредит.

## Форма

```json
"fonar": {
  "label": "Предложение",
  "headline": "суть оффера одной строкой",
  "body": "что входит в цену и чего в ней нет",
  "price": { "value": "", "note": "", "source": "" },
  "terms": [{ "label": "Первый взнос", "value": "" }],
  "deadline": { "text": "", "validUntil": "ГГГГ-ММ-ДД", "source": "", "showCountdown": false },
  "scarcity": { "text": "", "remaining": 0, "source": "", "validUntil": "ГГГГ-ММ-ДД" },
  "ctaLabel": "Забрать условия"
}
```

Полный образец: `landings/_example/content/offer.example.json`.

## Железное правило: источник и дата

Срочность и дефицит существуют **только** структурированными полями,
и только с `source` и `validUntil`.

| Что | Требуется |
|---|---|
| `price.value` | `price.source` — кто подтвердил цену и когда |
| `deadline` | `validUntil` в будущем + `source` |
| `scarcity` | `validUntil` в будущем + `source` |

Валидатор роняет сборку, если источника нет или дата прошла.
`scarcity.remaining: 0` тоже блокирует: оффера, которого больше нет, на странице быть не должно.

`source` — это документ, а не отписка. «прайс застройщика от 01.08.2026»,
«выгрузка шахматки от 20.08.2026», «письмо отдела продаж». Не «по данным отдела продаж».

## Что по-прежнему запрещено

Те же слова **вне** офферного блока. «Успейте купить», «осталось 3 виллы»,
«акция заканчивается» в `hero`, `insight`, `faq` или разъяснениях — валидация падает.

Так устроено намеренно: цифру с источником и датой сказать можно,
лозунг без данных — нельзя.

Безусловно запрещено везде, включая оффер: гарантия доходности, «без риска»,
превосходная степень про рынок, серые схемы владения землёй.

## Обратный отсчёт

`deadline.showCountdown: true` включает счётчик к реальной дате из `validUntil`.
Привязать его не к чему, кроме настоящего срока: без `validUntil` валидатор падает.

Когда срок выходит, блок **скрывает себя сам** на клиенте — живой домен не должен
показывать протухшую акцию между релизами.

Ставьте `showCountdown` только там, где срок действительно жёсткий.
На мягком сроке счётчик читается как давление и бьёт по доверию.

## Тон

Оффер говорит цифрами и условиями, а не прилагательными.
«от 210 000 $, первый взнос 30%, сдача Q4 2027» работает.
«Уникальное предложение по невероятной цене» — нет.

## Проверка

```bash
node tooling/validate-landing.mjs --slug <slug>
```

Отдельно перед подключением домена: даты в `validUntil` ещё не прошли
и оффер совпадает с тем, что реально подтвердил застройщик.
