# Пресет квиза

Движок общий (`packages/quiz`). Ветка даёт **только пресет**: шаги, подписи, тексты маршрутов.
Копипастить движок в ветку запрещено.

## Принцип

Квиз квалифицирует и ведёт. **Сначала маршрут, потом контакт.**

- 4–6 шагов, один вопрос на экран
- назад без потери ответов, состояние в `localStorage`
- закончить можно анонимно — маршрут показывается в любом случае
- не спрашивать «вам интересна недвижимость?»

## Базовые шаги движка

`task` · `format` · `geo` · `budget` · `horizon` · `method`

Пресет ветки может: убрать шаг, переименовать `label` ответов,
добавить свой шаг (школа, yield-горизонт, готовность к leasehold).

**Id ответов не переименовывать** — на них завязаны правила маршрутизации.

## Пять маршрутов, которые движок обязан уметь

| id | Когда |
|---|---|
| `fit` | фокус домена совпал |
| `neighbor` | лучше соседний домен — обязателен `outboundHref` |
| `budget` | коридор не бьётся, честно сузить |
| `learn` | человек ещё изучает |
| `remote` | сделка без перелёта |

## Правила маршрутизации

`routing` — список правил, проверяется **сверху вниз, первое совпадение выигрывает**.
Поэтому специфичные правила ставятся выше общих.

```json
{ "route": "neighbor", "when": { "geo": ["compare"] } }
```

Все условия внутри `when` должны совпасть одновременно.
Валидатор проверяет, что каждый `stepId` и каждый ответ реально существуют в шагах.

## Тексты маршрутов

Формат: что мы поняли → что это значит → что предлагаем.

Контакт живёт **только внутри маршрута**. Канал берётся из `config.cta`.
Телефон не обязателен, если есть мессенджер.

Не обещайте того, чего нет: если данных по коридору нет — так и пишите,
а не «подберём что-нибудь».

## Куда класть пресет

1. `landings/<slug>/content/quiz.json` — полное переопределение для ветки (приоритет)
2. `packages/quiz/presets/<name>.json` + `config.quizPreset: "<name>"` — переиспользуемый пресет
3. иначе `packages/quiz/presets/base.json`

## События

`quiz_start` · `quiz_step` · `quiz_complete` · `quiz_route_<id>` · `cta_click`

Отправляются через адаптер `packages/analytics`. Провайдер — из `config.analytics.provider`.
Ключи и пиксели в репозиторий не коммитятся.

## Проверка

```bash
node tooling/validate-landing.mjs --slug <slug>   # схема + связность правил
```

Прогон в браузере: пройти до конца, убедиться, что маршрут появился
**без единого поля контакта**, и что после перезагрузки состояние восстановилось.
